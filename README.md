# Password Manager (FastAPI)

## Описание
Простое приложение для управления паролями с использованием FastAPI и PostgreSQL.

## Запуск проекта
1. Убедитесь, что у вас установлены Docker и Docker Compose.
2. Клонируйте репозиторий.
3. Перейдите в директорию проекта.
4. Запустите команду `docker-compose up`.
5. Приложение будет доступно по адресу `http://localhost:8000`.
6. По адресу `http://localhost:8000/docs` будет документация по эндпоинтам

## Тестирование
Для запуска тестов используйте команду `docker-compose run web pytest tests/test.py`.
